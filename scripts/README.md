# Scripts

- `prepare_libero_20.py`: build the 20-episode training and test subset.
- `load_libero_subset.py`: verify the first 10-episode subset.
- `smolvla_zero_shot_inference.py`: run one zero-shot prediction and save curves.
- `train_smolvla_500.ps1`: train the 500-step model.
- `evaluate_libero20_base_vs_500.py`: evaluate base and all 500-run checkpoints on 8 test episodes.
- `plot_base_vs_500_predictions.py`: generate the base versus 500 prediction figures.
- `save_libero_sample_preview.py`: export a sample camera preview.
